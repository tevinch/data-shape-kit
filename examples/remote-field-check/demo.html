Data Shape Kit / form components

Keep typing.
Check only what changed.

A remote field check that keeps input immediate, ignores stale results, and checks the current value before accepting a form.

Try the edge cases

This demo simulates a service locally. It makes no network requests. Use 3–32 lowercase letters, digits or hyphens; start and end with a letter or digit.

available
A successful check after 400 ms.
taken
A validation message blocks acceptance.
slow
A 1.4-second check. Change it while checking to cancel the old result.
offline
A simulated service error. Retry with a different value.
timeout
A stalled check expires after 1.8 seconds.

Typing waits 350 ms before checking. Submit immediately to skip that delay. Editing Note starts no checks. Reset clears the form; the last accepted values remain below it.
