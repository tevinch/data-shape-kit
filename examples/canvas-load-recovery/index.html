Canvas load recovery

Try a failed load or cancel a pending image. Then load a valid document and continue adding and removing objects on the same canvas.

Ready. The red square is the existing document.

When automatic rendering is off, use “Render explicitly” after editing. Loading a valid document always requests a render.

This example rejects failed top-level objects. Nested and background images can still be omitted. It does not provide rollback for arbitrary documents or custom code. See the README for recovery boundaries.
