Keep Delete inside the current frame

Compare Tiptap 3.31.3 with the optional IsolatedListDelete extension. Both editors keep StarterKit's ListKeymap enabled.

Choose Place cursor after A, then press forward Delete once (Fn + Delete on a Mac keyboard). The expected result is one list item AB in the first frame; the second frame remains C. Use Undo to restore the original document.

This fixture uses invented text and makes no data requests. It does not recover content already lost in another editor. See the source and setup guide for supported versions and scope.
