CSV or spreadsheet text → JSON or Markdown

Choose comma-separated CSV or tab-separated TSV. Every cell stays text. Nothing is uploaded.

Choose TSV for tab-separated spreadsheet text. Pasting replaces this box and parses it. After editing, choose Parse.

JSON: up to 1,000,000 UTF-16 code units, 10,000 rows and 256 columns. Files are saved only when you choose Download.

Markdown escapes punctuation and uses <br> for cell line breaks. Rendered whitespace may differ; HTML line breaks depend on your Markdown renderer.

Plain text only: no XLSX, HTML tables, merged cells or formatting. Choose the delimiter explicitly; CSV here uses commas, with double quotes around cells containing commas, line breaks or quotes. Double a quote inside a quoted cell. One final row separator ends the last row; additional blank rows remain. Pasted line endings are kept; editing the box uses the browser’s normalized line endings. Empty cells are marked “empty” in the preview and stay blank in Markdown or empty strings in JSON. Markdown requires rows of equal width.
