Spreadsheet text → JSON or Markdown

Try quoted, tab-separated clipboard text. Every cell stays text. Nothing is uploaded.

Pasting replaces this box with the new selection and parses it. After editing, choose Parse.

JSON: up to 1,000,000 UTF-16 code units, 10,000 rows and 256 columns. Files are saved only when you choose Download.

Preview

Paste a table or load the example to see the result.

View JSON

Markdown escapes punctuation and uses <br> for cell line breaks. Rendered whitespace may differ; HTML line breaks depend on your Markdown renderer.

Plain text only: no XLSX, HTML tables, merged cells or formatting. One final row separator ends the last row; additional blank rows remain. Pasted line endings are kept; editing the box uses the browser’s normalized line endings. Empty cells are marked “empty” in the preview and stay blank in Markdown or empty strings in JSON. Markdown requires rows of equal width.
