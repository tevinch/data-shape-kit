Spreadsheet text → JSON

Try quoted, tab-separated clipboard text. Every cell stays text. Nothing is uploaded.

Pasting replaces this box with the new selection and parses it. After editing, choose Parse.

Up to 1,000,000 UTF-16 code units, 10,000 rows and 256 columns. A file is saved only when you choose Download JSON.

Preview

Paste a table or load the example to see the result.

View JSON

Plain text only: no XLSX, HTML tables, merged cells or formatting. One final row separator ends the last row; additional blank rows remain. Pasted line endings are kept; editing the box uses the browser’s normalized line endings. Empty cells are marked “empty” in the preview and remain empty strings in JSON.
